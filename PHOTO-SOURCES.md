# Visual sources

Displayed scenic visuals are original geometric SVG illustrations, dedicated under CC0 1.0. The social PNG is a rasterized copy. Public credits: /ILLUSTRATION-CREDITS.txt. Visible captions and alt text identify them as symbolic illustrations, not photographs, route diagrams, copies of a particular sculpture or current views.

Former Wikimedia/Panoramio file references have been retired from display, fallback, metadata and schema. No local photographic JPEG existed in the baseline. Their titles described an approach road to the attraction; they did not substantiate the former interior, tunnel or viewpoint captions, and the old credit omitted exact authors/licence versions. Their file pages could not be verified during this revision. The previous references remain in repository history; the unused photo-download script is retained only as an archival utility and must not be used to restore unverified images.
